## 1. Exact Rules

### 1.1 Trigger and Timeframe
- Operates exclusively on completed **5-minute spot candles**.
- Tick data (`on_tick`) produces **no entries**.
- Candle timeframe must strictly equal `5`.

### 1.2 Minimum Range vs. ATR Filter
- Evaluates candle range: $\text{Range} = \text{High} - \text{Low}$.
- Condition: $\text{Range} \ge 1.0 \times \text{ATR}(14)$.
- If $\text{Range} < 1.0 \times \text{ATR}(14)$, the candle is rejected (no trade).

### 1.3 Body-to-Range Ratio & Classification
- Evaluates candle body: $\text{Body} = |\text{Close} - \text{Open}|$.
- Body ratio: $\text{Body Ratio} = \frac{\text{Body}}{\text{Range}}$.
- **Doji Filter:** If $\text{Close} == \text{Open}$ or $\text{Range} \le 0$, rejected immediately.
- **Minimum Gate:** $\text{Body Ratio} \ge 0.45$. If $< 0.45$, rejected.
- **Classification Variants:**
  - $\text{Body Ratio} \ge 0.65$: Classified as `HIGH_CONVICTION`.
  - $0.45 \le \text{Body Ratio} < 0.65$: Classified as `BASELINE`.

### 1.4 Trade Direction & Derivative Instrument
- **Bullish Candle** ($\text{Close} > \text{Open}$):
  - Long signal: Buy Call Option (`CE`).
  - Spot technical stop reference: `candle.low`.
- **Bearish Candle** ($\text{Close} < \text{Open}$):
  - Short signal: Buy Put Option (`PE`).
  - Spot technical stop reference: `candle.high`.

### 1.5 Stop Loss & Exit Rules (Option Premium)
- **Initial Hard Stop:** `-15.0 PP` (Points in option premium from fill price).
- **Dynamic Stepped / Trailing Stop:**
  - When Peak Favorable Excursion ($\text{Peak Fav}$) reaches $\ge +4.0\text{ PP}$:
    - Lock stop at $+1.0\text{ PP}$.
  - When $\text{Peak Fav}$ reaches $\ge +8.0\text{ PP}$:
    - Trail stop at $\text{Peak Fav} - 3.0\text{ PP}$.
  - **Monotonicity Invariant:** Trailing stop **never loosens**; it only ratchets upward.
- **Verified Profit Target:** None (`fixed_target_pp = None`). Trades are managed purely by the stepped trailing stop.

### 1.6 Session Timing (Asia/Kolkata)
- **Entry Window Start:** `09:20 IST`. No new positions allowed prior to 09:20.
- **Entry Window End (Strategy Cutoff):** `14:45 IST`. No new entries allowed after 14:45.
- **Platform Hard Cutoff:** `15:00 IST`. System-level guard blocks all new entries at or after 15:00.
- **Forced EOD Square-Off:** At or after `15:00` / `15:15 IST`, all open positions must be closed.

## 2. ATR Precedence Hierarchy

When resolving the 14-period Average True Range ($\text{ATR}(14)$), the strategy adheres strictly to the following 5-tier precedence order:

| Tier | Source | Condition |
|---|---|---|
| **1** | `candle.atr14` | Present on the incoming candle object and $> 0$. |
| **2** | `candle.atr` | Present on the incoming candle object and $> 0$. |
| **3** | `context.market_metrics["atr14"]` | Present in strategy context metrics dictionary and $> 0$. |
| **4** | Rolling TR/ATR approximation | Computed from at least 14 completed 5-minute candles stored in strategy history: $\text{ATR}_{14} = \frac{1}{14}\sum_{i=1}^{14}\text{TR}_{-i}$. |
| **5** | Fallback default (`15.0`) | Explicitly documented fallback used only if tiers 1–4 are unavailable (e.g. at session start before 14 candles accumulate and no external ATR feed is connected). |
